titulo: O Pix da conversa vai com um link de página que tem o botão "Copiar código Pix" e nunca vence
---

Quando o agente (ou a equipe, pela conversa) manda um Pix da Stripe, a mensagem passa a trazer um link para uma página com o valor, um botão grande "Copiar código Pix", o QR Code e o passo a passo. Não é preciso mais tocar e segurar no código. Se o código passou da validade de uma hora, abrir a página gera outro no mesmo valor e com os mesmos dados de quem paga; se já foi pago, a página mostra "Pagamento confirmado". O código continua indo na mensagem seguinte, de reserva. Não há configuração: vale para toda organização com a Stripe conectada.
