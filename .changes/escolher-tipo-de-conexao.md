titulo: "Conectar WhatsApp" passa a perguntar como conectar — QR code ou API oficial — e diz a diferença
---

A tela de Conexões ganhou um botão **Conectar WhatsApp** que abre uma escolha com as duas formas lado a lado: **Sem API (QR code)** e **API oficial (Meta)**. Cada lado diz como conecta, o que custa, o risco e os limites, e para que é indicado — QR code para atendimento e conversa, API oficial para funil fixo e volume. Os limites mostrados (mensagem repetida barrada, limite diário de número novo, horário de envio) são os mesmos que o sistema aplica. A escolha leva ao passo a passo que já existia em cada aba.

No painel do gatilho de um fluxo, em "Números que este fluxo responde", o número conectado por QR code passa a mostrar um aviso de que mensagem repetida e volume diário são limitados nele. Não há ação para quem opera a VPS.
