titulo: O Pix na conversa sai só com o passo a passo, o código e o link de cartão
---

A cobrança por Pix na conversa volta a ter três balões: o passo a passo de onde colar o código, o código
copia e cola sozinho e, quando há, o link para pagar no cartão. O link da página com o botão "Copiar código
Pix" saiu da mensagem. A página continua abrindo para quem já recebeu o link.
