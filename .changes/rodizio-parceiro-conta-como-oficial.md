titulo: Rodízio de números divide por igual entre a API oficial direta e a do provedor parceiro
---

Os números conectados pelo provedor parceiro (Zernio) usam a mesma API oficial da Meta, mas o
rodízio os tratava como os de QR: só recebiam leads quando o número oficial direto enchia ou
descansava. Agora os dois entram juntos no primeiro grupo e dividem os cliques pela fração do
limite diário de cada um; os números por QR seguem como reserva.
