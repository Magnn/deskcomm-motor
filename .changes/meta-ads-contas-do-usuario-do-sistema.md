titulo: Conectar o Meta Ads com Facebook lista as contas também quando o login emite token de usuário do sistema
---

Com a configuração do "Login do Facebook para Empresas" que emite token de usuário do
sistema, a volta do Facebook terminava em "A permissão de leitura dos anúncios não foi
concedida", mesmo com a permissão dada: a plataforma recusa a esse tipo de token a lista de
contas da pessoa. O sistema agora lê as contas atribuídas no consentimento.
