titulo: Um botão só para conectar o WhatsApp, e a janela da Meta na versão nova
---

Em Conexões, conectar um número de WhatsApp agora é só pelo botão "Conectar WhatsApp". Ele pergunta a forma — QR code ou API oficial — e cada uma segue em janela: o QR code aparece na hora, e a API oficial abre a janela do Facebook ali mesmo, sem levar a outra aba para clicar num segundo botão. Os botões "Conectar por QR" da aba de números e "Conectar com Facebook" da aba da API oficial saíram.

A janela do Facebook passou a abrir no formato da versão 4 do cadastro da Meta. O formato anterior era o da versão 2, que a Meta descontinuou em 15/10/2026 e que não mostrava a tela de escolher ou criar outro portfólio empresarial (BM). Se a configuração de login do seu app da Meta foi criada antes da versão 4, crie uma nova em Login do Facebook para Empresas › Configurações (variação "Cadastro Incorporado", produto Cloud API) e cole o ID em Admin › API Oficial.
