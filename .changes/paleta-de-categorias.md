titulo: As cores dos tipos de caixa do construtor de fluxo passam a vir do tema
---

No construtor de fluxo, cada tipo de caixa tem uma cor (roxo para ação, verde para início, âmbar para espera…). Essas cores estavam escritas direto em cada tela, com uma regra à parte para o tema escuro. Agora elas vêm de uma paleta de categorias no tema: sete matizes, cada um com a cor, o fundo suave e o texto sobre o fundo, no claro e no escuro.

As cores continuam as de antes. Tons muito próximos foram unificados no mesmo matiz — laranja com âmbar, índigo com roxo, rosado com vermelho, azul-céu com azul.
